# A4一页纸模板

> 适用于门店留存、媒体资料包、经销商手册等场景。

---

## 排版结构

```
┌─────────────────────────────────────────┐
│  [技术名]                                 │
│  Slogan（一句话承诺）                      │
├─────────────────────────────────────────┤
│                                         │
│  【在[场景]，你能感受到什么？】              │
│  · 场景1：收益1                          │
│  · 场景2：收益2                          │
│  · 场景3：收益3                          │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│  【技术亮点：凭什么做到？】                 │
│  · 亮点1：参数/原理 → 用户收益            │
│  · 亮点2：参数/原理 → 用户收益            │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│  【实测数据/第三方认证】                   │
│  · 数据1：来源/条件                       │
│  · 数据2：来源/条件                       │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│  【搭载车型 & 权益】                       │
│  | 车型 | 方案 | 核心权益 |              │
│  |------|------|----------|              │
│                                         │
├─────────────────────────────────────────┤
│  门店体验预约 / 官网 / 客服热线           │
└─────────────────────────────────────────┘
```

---

## 设计原则

- **字号**：标题24pt+，正文10-12pt
- **配色**：品牌色为主，不超过3种颜色
- **图**：至少1张技术原理图/场景图/数据图
- **信息密度**：用户30秒内扫完关键信息
- **留白**：重要信息周围有呼吸空间

---

## 内容禁忌

- 不超过5个技术亮点（多则无重点）
- 不写"行业领先"等空洞词汇（改为具体数据）
- 不漏"适用边界"（坦诚反而建立信任）
