# 技术IP矩阵图模板

> 按七步法展开，填入对应内容即成完整技术IP矩阵。

---

## 第一步：Slogan（一句话承诺）

```
[技术名]，基于[技术]，在[场景]实现[可感知收益]，让[目标用户]更[价值形容词]。
```

**示例：** "千里浩瀚H9，基于双Thor冗余架构，在高速场景实现130km/h自动刹停，让长途驾驶更安全。"

---

## 第二步：技术品牌定位

一句话定位：[技术名]是____领域最____的方案

---

## 第三步：技术品牌愿景

3-5年后希望用户怎么认知这项技术？

---

## 第四步：用户体验

| 用户维度 | 具体体验描述 |
|----------|--------------|
| 旗舰安全 | __________ |
| 旗舰智能 | __________ |
| 旗舰素质 | __________ |
| 旗舰空间 | __________ |

---

## 第五步：技术亮点

按用户体验维度详细描述：

**旗舰安全：**
- 技术点1：___（含参数+场景+收益）

**旗舰智能：**
- 技术点1：___（含参数+场景+收益）

---

|----------|------|
| 算力 | __________ |
| 算法 | __________ |

| 生态 | __________ |
