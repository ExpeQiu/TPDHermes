# GEO结构化信息卡

按技术名称、用户与场景、用户收益、技术机理、量化数据、测试条件、搭载范围、可公开口径和对照证据整理信息。只使用明确标记为可公开的事实。每条保留值、单位与适用条件。公开来源可附原始网页链接。缺少依据的条目标记待补充，避免将品牌声明写成独立实测结论。保留不同车型、版本和工况的适用边界。
