# IP技术/事件传播稿字段说明

## 标题与发布信息

- `main_title`：主标题，突出技术核心与用户价值。
- `subtitle`：副标题，补充技术定位或发布意义。
- `city`：发布城市。
- `date`：发布日期。
- `company_name`：公司名称。
- `tech_brand_name`：技术品牌/平台名称。
- `domain`：所属领域，例如电动化、智能化、安全、补能生态。
- `core_user_value`：核心用户价值。
- `product_type`：产品类型或体验类型，例如出行、用车、智能座舱体验。

## 导语与技术亮点

`lead` 包含：

- `core_idea`：核心理念。
- `innovation_1`、`innovation_2`、`innovation_3`：关键创新技术。
- `performance_breakthrough`：关键性能突破。
- `subsystem`：具体子系统名称。
- `metric_improvement`：某项性能指标提升。
- `metric_reduction`：另一项指标降低。

## 主体内容

`problem_and_idea` 包含行业或用户挑战、底层架构、技术理念。

`tech_features` 使用列表，每个对象包含：

- `level`：技术层面。
- `tech_name`：技术名称。
- `effect`：技术效果描述。
- `scenario`：典型场景。
- `user_benefit`：用户利益描述。
- `pain_point`：解决的传统痛点。

## 领导言论与战略意义

`leader_quote` 包含职位、姓名、未来趋势、核心价值和引言。

`strategy_plan` 包含公司整体战略、未来年限、车型数量或系列、公司或行业愿景、生态愿景。

## 收尾信息

- `company_profile`：公司简介，建议 50 字以内。
- `media_contact`：联系人、邮箱、电话。
