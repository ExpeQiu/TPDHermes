# 领导讲稿字段说明

## 一、开篇

`opening` 包含：

- `greeting`：问候与欢迎。
- `technology_trend`：技术趋势。
- `market_change`：市场变化。
- `user_need_evolution`：用户需求演变。
- `core_announcement`：核心宣告语句。
- `tech_name`：核心技术名称/品牌。
- `value_proposition`：核心价值主张。

## 二、主体：技术叙事

`pain_points` 包含：

- `safety_anxiety`：安全焦虑。
- `range_anxiety`：续航焦虑。
- `homogenization`：体验同质化。
- `other`：其他痛点。

`vision` 包含：

- `solution_to_pain`：技术品牌如何解决痛点。
- `core_idea`：核心理念阐述。

`technology` 包含：

- `system_name`：核心理念命名或技术体系名称。

`pillars` 使用列表，每个对象包含：

- `name`：技术支柱名称。
- `principle`：核心原理。
- `data`：性能数据。
- `user_value`：用户价值。

`scenario_values` 使用列表，每个对象包含：

- `scenario`：用户场景。
- `tech_enablement`：技术如何赋能。
- `experience_improvement`：体验提升点。

`promise` 包含技术可靠性、安全标准、后续升级服务承诺。

## 三、结尾

`closing` 包含：

- `summary`：总结。
- `partners_ecosystem`：合作伙伴生态。
- `open_commitment`：开放承诺。
- `ecosystem_vision`：生态共建愿景。
- `call_to_action`：核心号召语句。
- `next_preview`：接下来内容预告。
- `thanks_to`：致谢对象。
- `ending`：结束语。
