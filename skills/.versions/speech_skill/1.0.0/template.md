# 发言稿模板

> 适用于发布会、上市活动、媒体沟通会等场景。

---

## 结构框架

```
【开场痛点】1-2分钟
在[具体场景]，用户常遇到[具体问题]……

【技术方案】3-5分钟
我们用[简明机理]解决[关键矛盾]……
[技术亮点1]：场景+数据
[技术亮点2]：场景+数据
[技术亮点3]：场景+数据

【用户价值】1-2分钟
因此在[可复现场景]，实现[量化指标]……
用户能感知到：[正向收益]

【收尾】
今天开始，[具体行动/权益]，欢迎大家体验。
```

---

## 开场痛点（参考）

> 各位好。
> 
> 不知道大家有没有这样的经历——开着车上了高速，前方突然出现障碍物，反应来不及；或者在地下车库找了半天车位，停进去才发现太窄下不来……
> 
> 这些场景，我相信在座每个人都遇到过。

---

## 技术亮点格式（示例）

```
[亮点名称]：解决[场景]的[痛点]
基于[技术原理]，实现[量化指标]
举个例子：[具体数据/实测案例]
```

---

## 收尾CTA（参考）

> 千里浩瀚，即日起在银河星耀8、银河E8全系标配。
> 大家可以到身边的吉利银河门店预约体验。
> 谢谢大家。

---

## 注意事项

- 语速：每分钟约200字，总时长控制在5-8分钟
- 数据：每项技术亮点配1个具体数据/实测
- 避免：参数堆砌、过度承诺、讲竞品弱点
- 必备：1个现场可复现的演示或体验承诺
