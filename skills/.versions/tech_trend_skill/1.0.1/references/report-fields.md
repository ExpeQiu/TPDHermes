# 技术发展趋势洞察报告字段说明

## 基础信息

- `title`：报告标题，默认使用“技术推广-车型项目管理流程-技术发展/品牌营销洞察报告”。
- `project_name`：项目或车型名称。
- `industry`：行业领域，例如智能电动汽车、智能座舱、补能生态等。
- `technology_domain`：本次分析聚焦的技术方向。
- `report_period`：报告周期，例如 2026 年度、2026 Q2。

## 一、技术趋势洞察

### 看行业趋势

- `macro_environment`：政策、经济、产业链、基础设施、用户认知等外部环境变化。
- `technology_change_direction`：技术演进方向，例如软件定义、智能化、平台化、生态化、数据闭环。
- `industry_lifecycle_stage`：判断技术处于导入期、成长期、快速扩散期、成熟期或重构期。

### 看市场/客户

- `customer_needs`：用户对技术的真实需求，要转译成用户收益。
- `customer_pain_points`：用户在认知、体验、信任、成本、安全、效率等方面的痛点。
- `unmet_needs`：当前产品体验或行业表达尚未满足的需求缺口。

### 看竞争

`competitors` 使用列表，每个对象包含：

- `name`：竞品或竞品品牌。
- `strengths`：技术优势。
- `weaknesses`：技术劣势或表达短板。
- `differentiation`：差异化突破口。

### 看自身

- `resource_capability`：研发、整车、供应链、渠道、品牌、用户运营等能力基础。
- `technology_shortcomings`：当前技术、体验、表达、证据、组织协同方面的不足。
- `advantage_accumulation`：已落地成果、工程能力、口碑、渠道或品牌资产。

### 看机会

- `strategic_opportunities`：可被产品、传播、体验或组织动作承接的机会点。
- `opportunity_priorities`：按影响力、可执行性、时间窗口和资源匹配度排序。

## 二、技术品牌营销洞察

- `industry_technology_features`：行业传播中高频强调的技术关键词。
- `communication_directions`：行业亮点宣发方向，以及可借鉴或需要避开的表达。
- `narrative_logic`：从用户问题、技术方案、场景证据到用户收益的叙事逻辑。
- `main_channels`：官网、发布会、短视频、社交媒体、门店体验、试驾、KOL、媒体评测等。
- `communication_cadence`：年度主题、季度战役、月度内容、节点引爆、持续复盘等节奏。

## 三、策略建议

- `trend_judgement`：技术发展趋势判断。
- `time_window`：未来 6-12 个月、12-24 个月或更长周期的机会窗口。
- `marketing_positioning`：一句话定义技术品牌的用户心智位置。
- `promotion_dimensions`：安全、效率、舒适、智能、生态、可靠等宣发维度。
- `channel_strategy`：不同渠道承担的传播、体验、转化或背书角色。
- `execution_cadence`：从梳理、发布、体验、扩散到复盘的阶段动作。
