# 技术IP包装全案策划字段说明

## 一、全案目标

- `tech_ip_name`：技术 IP 名称。
- `core_positioning`：核心定位，说明技术 IP 要占据的用户心智。
- `short_term_result`：短期 6 个月预期成果。
- `mid_term_result`：中期 12 个月预期成果。
- `long_term_result`：长期 24 个月预期成果。

## 二、背景洞察

- `industry_trend`：行业趋势，包括政策、用户需求、技术演进、传播风向。
- `market_competition`：市场竞争格局。
- `target_user_profile`：目标用户画像。
- `user_core_needs`：用户核心需求。
- `cognitive_barrier`：认知壁垒，例如概念复杂、信任不足、体验不可感知。

`competitor_ips` 使用列表，每个对象包含：

- `ip`：竞品 IP。
- `positioning`：核心定位。
- `communication_strategy`：传播策略。
- `learnable_point`：可借鉴点。

`resource_assessment` 包含：

- `technology_advantage`：技术优势。
- `brand_assets`：品牌资产。
- `channel_resources`：渠道资源。

## 三、技术 IP 亮点

`product_architecture` 包含：

- `core_layer`：核心层。
- `support_layer`：支撑层。
- `application_layer`：应用层。

`highlight_scenarios` 使用列表，每个对象包含：

- `scenario`：场景。
- `technology_support`：技术支撑。
- `user_value`：用户价值。
- `communication_angle`：传播角度。

## 四、项目策略

`model_lock_steps` 使用列表，每个对象包含：

- `stage`：阶段，例如预热、发布、深化、长效。
- `time`：时间。
- `model_node`：车型节点。
- `ip_action`：技术 IP 动作。
- `brand_action`：品牌动作。

- `core_narrative`：核心叙事主线。
- `differentiated_positioning`：差异化定位。
- `maintenance_strategy`：长期维护策略。

## 五、执行交付

`project_roles` 使用列表，每个对象包含 `role`、`responsibility`、`deliverable`。

`resource_list` 包含：

- `tech_display`：技术展具。
- `tech_certification`：技术认证。
- `tech_video`：技术视频。
- `offline_event`：线下活动。
- `other_materials`：其他物料。

`budget_items` 使用列表，每个对象包含 `category`、`budget`、`note`。

`control_mechanism` 包含：

- `milestone_check`：里程碑检查。
- `quality_gate`：质量门禁。
- `risk_plan`：风险预案。
