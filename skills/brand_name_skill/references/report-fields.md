# 技术品牌策略/命名报告字段说明

## 一、技术品牌洞察

`brand_insight` 包含：

- `industry_trend`：行业趋势。
- `market_competition`：市场竞争格局。
- `user_cognition`：用户认知现状。
- `core_highlight`：技术品牌包装核心亮点。
- `market_position`：市场占位。
- `target_interpretation`：目标解读。
- `task_positioning`：任务定位。
- `differentiation_opportunity`：差异化机会。

## 二、技术品牌策略

`brand_strategy` 包含：

- `core_strategy`：核心策略。
- `differentiated_positioning`：差异化定位。
- `support_points`：策略支撑点。

`strategy_goals` 使用列表，每个对象包含：

- `dimension`：维度。
- `goal`：目标。
- `metric`：衡量指标。

## 三、技术品牌核心信息

`core_message_house` 包含：

- `top_message`：顶层信息，即核心理念。

`support_messages` 使用列表，每个对象包含：

- `content`：信息内容。
- `evidence`：佐证数据或支撑材料。

建议提供 3 条支撑信息；不足时使用“待补充”。

## 四、技术品牌核心节奏

`key_stages` 使用列表，每个对象包含：

- `stage`：阶段。
- `time_node`：时间节点。
- `stage_goal`：阶段目标。
- `key_message`：重点信息。
- `key_action`：关键动作。

`model_launch_bindings` 使用列表，每个对象包含：

- `model`：车型。
- `release_time`：发布时间。
- `brand_action`：技术品牌配合动作。
- `communication_focus`：传播重点。

## 命名补充建议

如用户要求输出命名方向，可在相关字段中补充：

- 命名关键词。
- 命名方向。
- 命名解释。
- 传播适配。
- 合规和注册风险提示。
