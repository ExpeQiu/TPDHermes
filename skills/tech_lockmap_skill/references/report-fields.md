# 技术规划与技术品牌互锁地图字段说明

## 基础信息

- `title`：报告标题，默认使用“技术推广-车型项目管理流程-技术规划与技术品牌互锁地图”。
- `template_version`：模板版本，默认 `v1.0`。
- `template_source`：模板来源，默认 `附录03`。

## 互锁关系总览

- Mermaid 图用于表达技术规划、车型节奏、品牌策略和用户触点之间的闭环关系。
- 默认关系为：技术规划 -> 车型节奏 -> 品牌策略 -> 用户触点 -> 技术规划。

## 一、技术规划节点

`technology_nodes` 使用列表，每个对象包含：

- `time_node`：时间节点，例如 2026 Q1、SOP 前 3 个月、上市前 60 天。
- `milestone`：技术里程碑，例如技术冻结、量产验证、体验开放、OTA 发布。
- `model`：对应车型。
- `brand_binding`：品牌绑定点，说明该技术节点如何承接品牌表达。

## 二、车型节奏映射

`model_timeline` 使用列表，每个对象包含：

- `model`：车型。
- `launch_time`：上市时间或关键节奏。
- `technology`：搭载技术。
- `brand_focus`：品牌赋能重点。

## 三、品牌策略联动

`brand_actions` 使用列表，每个对象包含：

- `action`：品牌动作，例如发布会、技术日、门店体验、内容战役、用户共创。
- `linked_tech_node`：联动技术节点。
- `target_touchpoint`：目标用户触点。

## 四、用户触点规划

`user_touchpoints` 使用列表，每个对象包含：

- `touchpoint`：触点，例如官网、发布会、门店、试驾、社媒、KOL、售后、车机。
- `tech_message`：技术传递信息。
- `brand_tone`：品牌调性。
- `channel`：渠道。

## 五、互锁核查清单

`checklist` 使用列表，每项是一个核查事项。建议覆盖：

- 技术节点与车型节奏是否对齐。
- 品牌传播节点与工程节点是否匹配。
- 用户触点是否覆盖完整。
- 各部门协同责任是否明确。
