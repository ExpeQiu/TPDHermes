# 埋点事件命名白名单（P0）

本文用于固定埋点字段口径，优先保障“功能使用率：哪些功能被用、被谁用、频率如何”可稳定统计。

## 1. 命名规则

- `event_name`：`{feature}_{action}`，全小写，下划线分隔。
- `feature`：只允许使用白名单值（见下文）。
- `action`：只允许使用白名单值（见下文）。
- 禁止随意新增同义词（如 `open`/`view` 混用）。

## 6. 扩展规则（P1 以后）

- 新增 `feature` 或 `action` 前，先更新本白名单文档，再接入代码。
- PR 说明中必须列出新增埋点项（`event_name / feature / action / properties`）。
- 每周巡检“白名单外事件占比”，目标为 0。
