# 页面与接口映射

| 页面路径 | 主要使用的 API（均经 `src/lib/api.ts` 的 `apiV1()`） |
|----------|--------------------------------------------------------|
| `/` | 导航链至各模块 |
| `/projects` | `GET/POST /api/v1/projects/` |
| `/projects/new` | `POST /api/v1/projects/` |
| `/projects/[id]` | `GET/PUT/DELETE /api/v1/projects/{id}` |
| `/skills` | `GET/PATCH/DELETE … /api/v1/skills/…` |
| `/skills/market` | `GET /api/v1/skills/marketplace`、`POST /api/v1/skills/` |
| `/workshop` | `GET /api/v1/skills/`、`POST /api/v1/ws/generate` |
| `/workspace` | **重定向**至 `/workshop`（兼容旧链接） |
| `/knowledge` | `GET /api/v1/kb/collections`、`/kb/health`、`/kb/collections/.../query`、`/kb/cache/entries/...`；可选 `EventSource` `/api/v1/kb/events` |
| `/chat` | 默认 `NEXT_PUBLIC_CHAT_API_URL`（如 `http://localhost:8642/...`），与本仓库后端可选协同 |
| `/create` | 跳转聊天并带 query，不直接调 Hermes API |

全局组件：

- `KBDegradedBanner`：`GET /api/v1/kb/health`
- `Feedback`：若配置 `NEXT_PUBLIC_FEEDBACK_API_URL` 则尝试 POST，否则仅本地列表
