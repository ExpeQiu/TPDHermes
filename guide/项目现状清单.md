# TPDHermes 项目现状清单（2.0 基线）

## 技术栈

- 前端：Next.js 15（App Router）、React 19、TypeScript、Tailwind，源码在仓库根目录 `src/`。
- 后端：FastAPI、`backend/` 包、`main.py` 为 ASGI 入口（与 `backend` 内完整应用已对齐为单一入口）。
- 数据：SQLite + SQLAlchemy 异步；依赖 **`greenlet`**（已写入 `requirements.txt`）。
- 可选：外部 Chroma（`CHROMA_HOST`）、飞书（`FEISHU_*`）。

## 能力分级

| 类别 | 模块 | 说明 |
|------|------|------|
| 已可用 | 项目 CRUD | `/api/v1/projects` |
| 已可用 | 技能商店 API | `/api/v1/skills/*`（需 DB 注入） |
| 已可用 | 工坊 SSE | `POST /api/v1/ws/generate` |
| 已可用 | 知识库代理 | `/api/v1/kb/*`、SSE `/api/v1/kb/events` |
| 已可用 | 对话页 | 默认走 `/api/v1/chat/completions` 由本后端代理到 `Hermes-agent`，支持显式注入项目 / 知识库 / 技能上下文；开发环境联调验收已通过，见《[对话页联调验收记录-2026-05-14](./对话页联调验收记录-2026-05-14.md)》 |
| 半成品 | 用户反馈组件 | 无后端路由时仅本地演示 |
| 原型 | 技能市场目录 | 后端静态 `MARKETPLACE_CATALOG` |

## 启动方式

- 后端：`uvicorn main:app --reload --port 8000`（工作目录为仓库根，`PYTHONPATH` 含根目录）。
- 前端：`npm run dev`（默认 3000）。
- 一键：见仓库根 `start.sh`；验证：`verify.sh`。

## 已知已收口项（相对早期双入口）

- API 统一前缀 `/api/v1`。
- 前端通过 `NEXT_PUBLIC_API_URL` + `src/lib/api.ts` 访问后端。
- Docker/CI 与单仓目录一致。
